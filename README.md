# NeuroX - Multi-Disease Brain MRI Analysis System

## 📋 Project Overview

NeuroX is an advanced deep learning system for automated detection and segmentation of brain pathologies from MRI scans. The system simultaneously analyzes three critical neurological conditions: **Brain Tumors**, **Stroke**, and **Alzheimer's Disease** using state-of-the-art 3D convolutional neural networks with uncertainty quantification.

### Project Goal

To develop a clinically-viable AI diagnostic assistant that:
- Provides accurate multi-disease detection from a single MRI scan
- Generates precise 3D visualizations of brain pathology
- Quantifies diagnostic uncertainty for clinical decision support
- Meets publication-grade statistical rigor for medical AI research

## ⚡ Quick Start

Get the system running in under 5 minutes:

1.  **Clone & Install**:
    ```bash
    git clone https://github.com/SaiKarthik547/Capstone.git
    ```


## 🛠️ Technology Stack

### Core Framework
- **Python 3.8+** - Primary programming language
- **PyTorch 2.0+** - Deep learning framework
- **CUDA 11.8+** - GPU acceleration (optional)

### Medical Imaging
- **NiBabel** - NIfTI file I/O
- **HD-BET** - Medical-grade brain extraction
- **Scikit-image** - Image processing and marching cubes
- **SciPy** - Scientific computing and morphological operations

### Deep Learning Architecture
- **3D CNN Encoder** - Shared feature extraction (`enc1`→`enc2`→`enc3`→`bottleneck`)
- **Transformer Bottleneck** - Global context modeling (depth=4, heads=8, mlp=256)
- **Tumor & Stroke PresenceHeads** - Bottleneck → AdaptiveAvgPool → FC classifier
- **AlzheimerEncoder** - Raw MRI → 3× Conv3D blocks → dual pool (avg+max, 256-dim) → MLP → logit (fully independent)
- **Attention-Gated U-Net Decoders** - Tumor (3-class) and Stroke (binary) segmentation
- **InstanceNorm3d** - Normalization for small-batch stability
- **Metrics-embedded Checkpoints** - `ferrari_model.pth` stores weights + full training history

### Visualization
- **Streamlit** - Web application framework
- **Plotly** - Interactive 3D graphics
- **Trimesh** - 3D mesh processing
- **Matplotlib** - 2D plotting and analysis

### Evaluation & Statistics
- **Scikit-learn** - ML metrics and evaluation
- **Iterative-stratification** - Multi-label cross-validation
- **NumPy** - Numerical computing
- **Pandas** - Data analysis (optional)

### Report Generation
- **ReportLab** - PDF report creation
- **Groq AI** - Optional AI-powered insights (requires API key)

## 🏗️ System Architecture

### 🧠 Class Diagram — NeuroX Ferrari Architecture

```mermaid
classDiagram
    direction TB

    class NeuroXMultiDisease {
        +encoder : SharedEncoder
        +presence_heads : ModuleDict
        +seg_decoders : ModuleDict
        +alz_encoder : AlzheimerEncoder
        +forward(x, active_presence, active_seg) dict
    }

    class SharedEncoder {
        +in_channels : int = 1
        +forward(x) dict[enc1, enc2, enc3, bottleneck]
    }

    class EncoderBlock1 {
        +Conv3d(1, 32, k=3, p=1) x2
        +InstanceNorm3d(32, affine=True)
        +ReLU inplace=True
        +input  [B, 1, 96, 96, 96]
        +output [B, 32, 96, 96, 96]
        +MaxPool3d(2) gives [B, 32, 48, 48, 48]
    }

    class EncoderBlock2 {
        +Conv3d(32, 64, k=3, p=1) x2
        +InstanceNorm3d(64, affine=True)
        +ReLU inplace=True
        +input  [B, 32, 48, 48, 48]
        +output [B, 64, 48, 48, 48]
        +MaxPool3d(2) gives [B, 64, 24, 24, 24]
    }

    class EncoderBlock3 {
        +Conv3d(64, 128, k=3, p=1) x2
        +InstanceNorm3d(128, affine=True)
        +ReLU inplace=True
        +input  [B, 64, 24, 24, 24]
        +output [B, 128, 24, 24, 24]
        +MaxPool3d(2) gives [B, 128, 12, 12, 12]
    }

    class TransformerBottleneck3D {
        +dim : int = 128
        +depth : int = 4
        +heads : int = 8
        +mlp_dim : int = 256
        +dropout : float = 0.1
        +tokens : int = 1728 (12x12x12)
        +reshape input [B,128,12,12,12] to [B,1728,128]
        +4x PreNorm + MultiHeadAttention(8 heads)
        +4x PreNorm + FeedForward(128 to 256 to 128)
        +reshape output [B,1728,128] to [B,128,12,12,12]
    }

    class PresenceHead_Tumor {
        +in_features : int = 128
        +AdaptiveAvgPool3d(output=1)
        +Flatten gives [B, 128]
        +Linear(128, 64)
        +ReLU
        +Dropout(p=0.3)
        +Linear(64, 1) gives logit [B,1]
        +BCEWithLogitsLoss
        +MC-Dropout: 10 stochastic passes at inference
        +output: mean_prob_tumor and std_tumor
    }

    class PresenceHead_Stroke {
        +in_features : int = 128
        +AdaptiveAvgPool3d(output=1)
        +Flatten gives [B, 128]
        +Linear(128, 64)
        +ReLU
        +Dropout(p=0.3)
        +Linear(64, 1) gives logit [B,1]
        +BCEWithLogitsLoss
        +MC-Dropout: 10 stochastic passes at inference
        +output: mean_prob_stroke and std_stroke
    }

    class AlzheimerEncoder {
        +FULLY INDEPENDENT: zero shared params
        +raw MRI input [B, 1, 96, 96, 96]
        +forward(x) logit [B, 1]
        +MC-Dropout: classifier.train() x10 passes
    }

    class AlzBlock1 {
        +Conv3d(1, 32, k=3, p=1, bias=False) x2
        +InstanceNorm3d(32)
        +ReLU
        +input  [B, 1, 96, 96, 96]
        +MaxPool3d(2) gives [B, 32, 48, 48, 48]
    }

    class AlzBlock2 {
        +Conv3d(32, 64, k=3, p=1, bias=False) x2
        +InstanceNorm3d(64)
        +ReLU
        +input  [B, 32, 48, 48, 48]
        +MaxPool3d(2) gives [B, 64, 24, 24, 24]
    }

    class AlzBlock3 {
        +Conv3d(64, 128, k=3, p=1, bias=False) x2
        +InstanceNorm3d(128)
        +ReLU
        +input  [B, 64, 24, 24, 24]
        +NO MaxPool: output [B, 128, 24, 24, 24]
    }

    class AlzDualPool {
        +AdaptiveAvgPool3d(1) flatten gives [B, 128]
        +AdaptiveMaxPool3d(1) flatten gives [B, 128]
        +torch.cat([avg, max], dim=1) gives [B, 256]
        +AvgPool: captures global cortical atrophy
        +MaxPool: captures focal hippocampal peaks
    }

    class AlzClassifier {
        +LayerNorm(256)
        +Linear(256, 128)
        +GELU
        +Dropout(p=0.4)
        +Linear(128, 1) gives logit [B, 1]
        +BCEWithLogitsLoss
        +output: mean_prob_alz and std_alz
    }

    class AttentionGate_L3 {
        +W_gate : Conv3d(128, 64, k=1)
        +W_skip : Conv3d(128, 64, k=1)
        +psi    : Conv3d(64, 1, k=1)
        +forward: add then ReLU then psi then Sigmoid
        +alpha multiplied by enc3 skip
        +spatial scale: 12 to 24
    }

    class AttentionGate_L2 {
        +W_gate : Conv3d(64, 32, k=1)
        +W_skip : Conv3d(64, 32, k=1)
        +psi    : Conv3d(32, 1, k=1)
        +forward: add then ReLU then psi then Sigmoid
        +alpha multiplied by enc2 skip
        +spatial scale: 24 to 48
    }

    class AttentionGate_L1 {
        +W_gate : Conv3d(32, 16, k=1)
        +W_skip : Conv3d(32, 16, k=1)
        +psi    : Conv3d(16, 1, k=1)
        +forward: add then ReLU then psi then Sigmoid
        +alpha multiplied by enc1 skip
        +spatial scale: 48 to 96
    }

    class TumorDecoder {
        +output_channels : int = 3
        +labels: ET(4) NCR(1) ED(2)
        +up3: ConvTranspose3d(128,128,k=2,s=2)
        +dec3: Conv3d(256,128,k=3) x2 InstanceNorm
        +up2: ConvTranspose3d(128,64,k=2,s=2)
        +dec2: Conv3d(128,64,k=3) x2 InstanceNorm
        +up1: ConvTranspose3d(64,32,k=2,s=2)
        +dec1: Conv3d(64,32,k=3) x2 InstanceNorm
        +head: Conv3d(32, 3, k=1) full-res logits
        +loss: 0.5 x DiceLoss + 0.5 x FocalLoss(gamma=2, alpha=0.25)
    }

    class StrokeDecoder {
        +output_channels : int = 1
        +label: binary infarct mask
        +up3: ConvTranspose3d(128,128,k=2,s=2)
        +dec3: Conv3d(256,128,k=3) x2 InstanceNorm
        +up2: ConvTranspose3d(128,64,k=2,s=2)
        +dec2: Conv3d(128,64,k=3) x2 InstanceNorm
        +up1: ConvTranspose3d(64,32,k=2,s=2)
        +dec1: Conv3d(64,32,k=3) x2 InstanceNorm
        +head: Conv3d(32, 1, k=1) full-res logits
        +loss: 0.5 x DiceLoss + 0.5 x FocalLoss(gamma=2, alpha=0.5)
    }

    class TrainingConfig {
        +optimizer: AdamW(lr=2e-4, wd=1e-5)
        +alz_encoder group lr: 1e-4 (LR x 0.5)
        +scheduler: CosineAnnealingLR(T_max=20, eta_min=1e-6)
        +epochs=25, batch_size=1, ROI=96x96x96
        +Stage A ep1-5:   lambda_cls=1.5
        +Stage B ep6-15:  lambda_cls=1.5
        +Stage C ep16-25: lambda_cls=1.0
        +lambda_tumor=1.0, lambda_stroke=1.0
        +grad_clip: max_norm=1.0
        +AMP: autocast + GradScaler
        +seed=42, round-robin batch order
    }

    class CheckpointFile {
        +file: ferrari_model.pth
        +key[model_state]: OrderedDict weights
        +key[metrics][tumor_et]: list len=N_epochs
        +key[metrics][tumor_ncr]: list len=N_epochs
        +key[metrics][tumor_ed]: list len=N_epochs
        +key[metrics][tumor_mean]: list len=N_epochs
        +key[metrics][stroke_dice]: list len=N_epochs
        +key[metrics][alz_auc]: list len=N_epochs
        +key[metrics][alz_accuracy]: list len=N_epochs
        +key[metrics][alz_precision]: list len=N_epochs
        +key[metrics][alz_recall]: list len=N_epochs
        +key[metrics][alz_f1]: list len=N_epochs
    }

    NeuroXMultiDisease *-- SharedEncoder
    NeuroXMultiDisease *-- PresenceHead_Tumor
    NeuroXMultiDisease *-- PresenceHead_Stroke
    NeuroXMultiDisease *-- AlzheimerEncoder
    NeuroXMultiDisease *-- TumorDecoder
    NeuroXMultiDisease *-- StrokeDecoder
    SharedEncoder *-- EncoderBlock1
    SharedEncoder *-- EncoderBlock2
    SharedEncoder *-- EncoderBlock3
    SharedEncoder *-- TransformerBottleneck3D
    TumorDecoder *-- AttentionGate_L3
    TumorDecoder *-- AttentionGate_L2
    TumorDecoder *-- AttentionGate_L1
    StrokeDecoder *-- AttentionGate_L3
    StrokeDecoder *-- AttentionGate_L2
    StrokeDecoder *-- AttentionGate_L1
    AlzheimerEncoder *-- AlzBlock1
    AlzheimerEncoder *-- AlzBlock2
    AlzheimerEncoder *-- AlzBlock3
    AlzheimerEncoder *-- AlzDualPool
    AlzheimerEncoder *-- AlzClassifier
    NeuroXMultiDisease ..> TrainingConfig : trained with
    NeuroXMultiDisease ..> CheckpointFile : saved to / loaded from
```
